# Blood Bank Database (Microsoft Access)

A relational database for a regional blood bank network, built at De Montfort University (2025).

## What I built
- Tables and relationships for donors, appointments, laboratory staff and blood inventory
- Queries to retrieve and update records
- Forms for data entry and reports for summaries
- A design aimed at reducing manual data entry and scheduling problems

## Tools
Microsoft Access, SQL

## How to open
1. Open Microsoft Access.
2. Download the `.accdb` file from this repository and open it.
